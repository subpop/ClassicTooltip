ClassicTooltip
----------------------------------------
Recreates the tooltips from the initial release

DESCRIPTION
----------------------------------------
ClassicTooltip is an AddOn that reverts tooltips back to the way they were at “release”. It adds the colored backgrounds back in, and removes some of the more detailed tooltip information.

INSTALLATION
----------------------------------------
Copy the ClassicTooltip directory into your World of Warcraft/Interface/AddOns directory.

PROBLEMS?
----------------------------------------
